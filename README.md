# AI Fluency Assignment Coach

## What it does

AI Fluency Assignment Coach helps students understand an assignment in simple words. A student uploads an assignment screenshot or PDF and asks the coach to explain:

- The goal in easy words
- Exact deliverables
- A step-by-step plan
- What to submit
- A final checklist

## Who it is for

This agent is for AI Fluency students who want to understand assignment requirements before starting their work.

## Platform and setup

This agent was built as a Claude Project.

### Setup steps

1. Open Claude.
2. Go to Projects.
3. Create a project named `AI Fluency Assignment Coach`.
4. Add project instructions telling the agent to use simple language and only use information from the uploaded assignment.
5. Upload an assignment screenshot or PDF.
6. Send this prompt:

```text
Read this assignment and give me:
- the goal in easy words
- exact deliverables
- a step-by-step plan
- what I need to submit
- a final checklist
```
